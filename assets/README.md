# assets/

Shared files used by every video.

| Folder | What goes in it |
|---|---|
| `brand/` | your logo and banner (PNG with transparency is best). Set their paths in `CHANNEL_PROFILE.md`. |
| `fonts/` | the fonts named in the profile (`.ttf`/`.otf`). Use fonts whose licence allows video use (Google Fonts are OFL). |
| `people/` | approved cutouts of named people: `<first-last>.png` + `<first-last>.json` (source, URL, licence, date, modifications). See `docs/rules.md` §4. |
| `maps/` | base map data (Natural Earth, public domain) for map graphics. |

The kit ships **no music or sound effects**: their licences allow using them in your own videos but not
redistributing the files. The render is voice only; add music in your own editor if you want.
