# tools/

The Python tools of the kit. What each one does and when it runs: `docs/SOP.md` (quick reference at the end).

Run them from the kit's root folder with one of the two environments the installer creates:
- `py-audio` = `tools/venv_audio` (transcription, alignment, cut, audio QA)
- `py-render` = `tools/venv_render` (graphics, storyboard, render, video QA)
